# ChemDraw App

Generate chemical structure grids from molecular formulas directly in your browser!  

![Demo Screenshot](images/demo.png)

---

## Features
- Enter a molecular formula like `C6H6` or `CH4`  
- Automatically generate **all isomers** of the molecule  
- View results as a neat **grid of chemical structures**  
- Supports multiple users with temporary PNG handling  
- Download generated images for your records

---

## How to Use
1. Enter a chemical formula in the input box (e.g., `C6H6`)  
2. Click **Generate**  
3. The grid of molecular structures will appear below  
4. Click **Download** to save the PNG locally

---

## Supported Elements
- **C** (Carbon)  
- **H** (Hydrogen)    
- Valid formulas include numbers after each element, e.g., `C6H6` or `C4H8`
